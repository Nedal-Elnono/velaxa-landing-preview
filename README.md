لاندينج بيدج للعلاج السياحي (زراعة الأسنان في تركيا) مستهدفة السوق الأمريكي.
HTML / CSS / JS خالص — مفيش frameworks ولا build step. ارفع الفولدر على أي هوست وهيشتغل.

النسخة الأولى لسه موجودة في الفولدر الأب ومشتغلة.

## النشر والتحديث

```bash
./deploy.sh "وصف التعديل"     # بيرفع على الريبو الخاص + اللينك اللايف
```

الصفحة بتتحدث خلال 30–60 ثانية.

| الريبو | النوع | الدور |
|---|---|---|
| `Nedal-Elnono/velaxa-landing` | **private** | مصدر المشروع |
| `Nedal-Elnono/velaxa-landing-preview` | public | اللي GitHub Pages بيقدّم منه |

المدفوعة. الريبو الأساسي فضل private زي ما هو مطلوب، والعام ده مجرد وجهة نشر —
تقدر تمسحه في أي وقت من غير ما يأثر على المشروع.

**بديل:** فيه نسخة كمان على Cloudflare Pages
(`velaxa-landing.pages.dev`) بس دومين `pages.dev` طلع محجوب على شبكتك، عشان كده
GitHub Pages هو اللينك المعتمد.

## ربط الفورم بـ Google Sheets

الصفحة فيها **فورمين** (الهيرو + سكشن الحجز) — الاتنين بيشتغلوا من نفس الكود.

1. Google Sheet بالأعمدة: `submittedAt | fullName | country | state | countryCode | whatsapp | reference | page`
2. Extensions → Apps Script:

```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSpreadsheet().getActiveSheet().appendRow([
    d.submittedAt, d.fullName, d.country, d.state || "",
    d.countryCode, d.whatsapp, d.reference || "", d.page
  ]);
  return ContentService.createTextOutput("ok");
}
```

3. Deploy → New deployment → **Web app** → Execute as **Me** → Access **Anyone**
4. حط الـURL في `SHEET_ENDPOINT`

## إضافة محتوى

**لوجو جديد في شريط الشهادات** أو **ريفيو جديد** — سطر `<li>` واحد في `index.html`.
الجافاسكريبت بيقيس عرض الشريط لوحده، بيكرر العناصر عشان تملا الشاشة، وبيعمل نسخة
مطابقة عشان اللوب يدور من غير قطع. سواء عنصر واحد أو عشرة.

**تبديل صورة الهيرو** — استبدل `hero-patient.webp` (+ `@2x`). الـCSS بيثبتها
بارتفاعها وحافتها، فأي صورة قص جديدة هتقع في نفس المكان؛ ظبط `object-position`
بس لو الشخص في مكان مختلف في الكادر.

## الريسبونسف

نقاط الكسر: **1000px** (النافبار يبقى قائمة) · **860px** (الأعمدة تتراص) · **560px** (موبايل ضيق)

تحت 860px الهيرو بيبقى عمود واحد: الكلام فوق والكولاج تحته.

متحقق منه على **13 مقاس** من 320px لـ 1920px: صفر تمرير أفقي، وزرار الواتساب
متوسط بالظبط في كل واحد منهم.
